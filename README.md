# One Letter for Your Day

One letter standing for the word that describes my day, written for the [Make.fun bounty](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

`main.py` writes the letter to `/output/entry.txt`:

> Z

Z for zombie — the day I shuffled through half-asleep, running on nothing, answering in groans. The letter itself is the sound of sleep: Zzz.

Run it with `python3 main.py`.
